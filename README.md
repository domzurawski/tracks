# Tracks

Lap time tracking and leaderboards for track-day drivers.

## Getting Started

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Agentic workflow

This project uses [superpowers](https://github.com/obra/superpowers) for spec-driven, plan-based agentic development.
